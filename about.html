Project Overview

This project was built to illustrate the fundamental principles of Git version control:

  • Repository Initialization
  • Staging and Committing Changes
  • Feature Branching and Merging
  • Ignoring Build & Log Artifacts using .gitignore
  • Safe Undo Operations
  • Remote Synchronization with GitHub
  • Adding one more List item in feature branch
